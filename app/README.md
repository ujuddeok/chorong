# chorong-app

Chorong's GPU-rendered viewer.

Part of Chorong, a fast, read-only code viewer built for reading code.

The binary is `chorong-app`. Building it needs GPUI's system packages; see
[docs/public/building.md](../docs/public/building.md).

See the [main README](../README.md) for what Chorong does and how to get it.
