# The viewer's own icons

Icons only the viewer uses, served next to the shared set in `crates/cho-layout-ui/assets/icons`
(`app/src/assets.rs`). [Lucide](https://lucide.dev) 0.460.0 (`lucide-static`), ISC licence: see
`crates/cho-layout-ui/assets/icons/LICENSE-lucide.txt`. Unmodified.

- `link.svg`, `unlink.svg`: the chain on a linked (or unlinked) Compare Side by Side column.
