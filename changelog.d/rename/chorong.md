- Odin is now **Chorong**: the viewer is `Chorong.app` / `chorong-app` and the command-line tool
  is `cho`. Links are `chorong://`, environment variables `CHORONG_*`, the config and cache
  folders `chorong`, repository folders `.chorong/`, and investigation files use `"chorong": N`.
- Nothing reads the old names: move your settings folder, enter tokens again, rename `.odin/`
  folders and the `"odin"` key in investigation files, reinstall the agent skill, and update
  links, `ODIN_*` variables and scripts. The user guide's "Upgrading from the earlier name"
  lists the steps.
