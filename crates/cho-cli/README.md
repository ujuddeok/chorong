# chorong

Chorong's headless command-line interface, for people and agents.

Part of Chorong, a fast, read-only code viewer built for reading code.

Install the `cho` command with `cargo install chorong`. It runs the same engine as the
viewer, with `--json` output for scripts and agents. Commands are documented in
[docs/public/cli.md](../../docs/public/cli.md).

See the [main README](../../README.md) for what Chorong does and how to get it.
