# Fonts

[IBM Plex](https://github.com/IBM/plex) Sans 2.005 (Regular, Medium, SemiBold) and Mono 2.005 (Regular, Italic, Medium),
SIL Open Font License 1.1: see `OFL-IBM-Plex.txt`. Unmodified TTFs from the IBM/plex
repository (`packages/plex-sans` and `packages/plex-mono`). They are Chorong's default UI and code
fonts; the `appearance.ui_font` and `appearance.code_font` settings choose others.
