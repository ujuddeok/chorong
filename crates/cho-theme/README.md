# cho-theme

Loads Zed theme files (schema v0.2.0) for Chorong.

Part of Chorong, a fast, read-only code viewer built for reading code. This crate is one of
the libraries the Chorong viewer (`chorong-app`) and the `cho` CLI (`chorong`) are built from; its
API follows their needs and may change between releases.

See the [main README](../../README.md) for what Chorong does and how to get it.
